# قدرات | مساحة التدريب

إصدار الإصلاح: 2026.10.04. تطبيق عربي ثابت للتدريب الشخصي على 1000 سؤال لفظي وكمي.

## التشغيل على خادم مع حسابات الطلاب (جديد)

`npm start` (Node.js 22.13+، بلا تثبيت حزم) ثم افتح http://localhost:8080. يسجّل الطالب ويُحفظ تقدمه في حسابه، وللمدير لوحة `/admin.html`. التفاصيل والنشر في `DEPLOY.md`.

## التشغيل بدون خادم

1. فك الحزمة كاملة.
2. افتح `dist/PROJECT_GUIDE.html` للدليل الكامل.
3. على Windows شغّل `dist/START_WINDOWS.bat` بعد تثبيت Python 3.
4. أو من مجلد dist شغّل `python3 serve.py` على macOS/Linux.
5. عنوان التشغيل: http://127.0.0.1:8765/index.html.

يمكن فتح `dist/index.html` مباشرة، لكن الحفظ على عنوان محلي ثابت أكثر استقرارًا من file://.
لا يحتاج التشغيل إلى إنترنت أو npm install أو API keys. تظل نتائج الطالب في متصفحه؛ انقلها بملف JSON من إدارة البيانات.

## الاختبارات الحالية

Node.js 18+ وPython 3. من جذر المشروع:

```sh
npm test                       # الخادم + الاختبارات الثلاثة التالية
node scripts/test-server.cjs
node scripts/test-site.cjs
node scripts/test-learning.cjs
node scripts/test-reliability.cjs
python scripts/test-batch-08.py
```

تستخدم اختبارات الواجهة DOM test doubles وليست اختبارات متصفح مرئية. اختبار XLSX يتطلب أن يتوفر أمر `python`.
اختبارات الدفعات 1–7 تاريخية وقد تتوقع بيانات وقت الدفعة. لا تعِد تشغيل سكربتات المراجعة على البنك الحالي.

## تحديث البنك

حرر `dist/data.json` ثم شغّل:

```sh
python scripts/sync-data.py
```

هذا يولّد `dist/data.js`. أعد تشغيل الاختبارات قبل النشر. علامة review لا تُضاف إلا بعد مراجعة المحتوى فعليًا.

## الهيكل

- server: خادم Node بلا اعتماديات (حسابات، جلسات، حفظ التقدم في SQLite، لوحة الإدارة) وأوامر cli.js.
- dist/account.js: شاشة الدخول ومزامنة مساحة الطالب مع حسابه؛ يحمّل بقية الملفات بعد التحقق.
- dist/admin.html و admin.js: لوحة الإدارة.
- dist: كل ملفات التشغيل والمراجع وقالب Excel ودليل المشروع.
- scripts: اختبارات الإصدار وسجل تغييرات الأسئلة وأدوات المراجعة.
- .openai/hosting.json: تعريف الاستضافة الحالية، دون أسرار.
- CHANGELOG.md: الإصلاحات وحدود التحقق.

ترتيب التحميل: account.js ثم jszip، data.js، core.js، app.js، learn.js، engine.js. يبدأ التطبيق مرة واحدة في engine.js، وهو التعريف النهائي للتوقيت والمراجعة وقياس التقدم.

## حدود الاستخدام

تدريب مستقل وليس منتجًا رسميًا لقياس. النسبة ليست درجة معيارية. المراجعة داخلية وليست اعتمادًا مستقلًا. الحسابات والمزامنة تعمل فقط عند التشغيل عبر server؛ لا توجد مراقبة امتحانية. ملفات PDF مراجع المستخدم الأصلية. ترخيص JSZip داخل dist/vendor.
