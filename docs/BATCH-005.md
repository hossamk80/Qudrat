# الدفعة الخامسة (١٠٠ سؤال) — الأسئلة ٤٠١–٥٠٠

المؤلّف: Claude · التاريخ: ٢٠٢٦/١٠/٠٦ · الملفات: `content/batch-005-{quant,verbal,reading}.json`

## ١ — اختيار المهارات: قياس قبل التأليف

قبل كتابة سؤال واحد قِستُ البنك كله (١٤٨٩ مهاجرًا + ٤٠٠ مؤلَّفًا = ١٨٨٩) موزّعًا
على الثلاثين مهارة والصعوبات الثلاث، لأؤلّف حيث ينقص لا حيث يسهل. فظهر أن
الشُّحّ كله في **الصعب**، وأن أرضيته ١٠ أسئلة فقط في `VR-MAIN`.

| المهارة | صعب قبل ← بعد | متوسط قبل ← بعد |
|---|---|---|
| VR-MAIN | ١٠ ← **١٦** | ٢٥ ← ٢٥ |
| QL-EXPRESS | ١٢ ← **٢٣** | ١٨ ← ١٨ |
| QR-PROPORTION | ١٢ ← **٢٣** | ٢٥ ← ٢٥ |
| QG-ANGLE | ١٣ ← **٢٤** | ٢٦ ← ٢٦ |
| QL-EQUATION | ١٣ ← **٢٤** | ٢٦ ← ٢٦ |
| QS-DATA | ١٤ ← **٢٥** | ١٦ ← ١٦ |
| QS-CENTER | ١٤ ← **٢٥** | ١٨ ← ١٨ |
| VC-CONTEXT | ١٤ ← **٢٤** | ١٣ ← ١٣ |
| VR-MEANING | ١٧ ← **٢٣** | ١٢ ← ١٢ |
| VR-DETAIL | ١٧ ← ١٧ | ٤ ← **١٠** |
| VR-PURPOSE | ١٧ ← ١٧ | ٩ ← **١٥** |

وأرضية الصعب في البنك كله ارتفعت من **١٠ إلى ١٥**، وأشحّ المهارات الآن
`QA-PERCENT` و`QW-RATE` و`QP-PROB` عند ١٥ — وهي هدف الدفعة القادمة.

**لماذا الدفعة كمّية في أغلبها؟** لأن الثقوب كذلك: ستّ من أشحّ ثماني مهارات
كمّية. والتوزيع ٦٦ كمّيًّا و٣٤ لفظيًّا ليس اختيارًا في التوازن، بل نتيجة القياس.

**ولماذا `VR-MAIN` ارتفعت ٦ لا ١١؟** لأن سؤال «الفكرة الرئيسة» واحد لكل نص
بطبيعته، فلا يُرفع إلا برفع عدد النصوص. وستّة نصوص جديدة هي ما يَحمل أربعةَ
أسئلة لكلٍّ منها بالتوزيع الذي اعتمدناه (٣–٤ أسئلة للنص الواحد).

## ٢ — التركيب

- **٦٦ كمّيًّا**، كلها صعبة، **ولكلٍّ تعبير تحقّق** يحسب مفتاحه: `QL-EXPRESS` ١١،
  `QR-PROPORTION` ١١، `QG-ANGLE` ١١، `QL-EQUATION` ١١، `QS-DATA` ١١،
  `QS-CENTER` ١١.
- **١٠ لفظيًّا** في إكمال الجمل (`VC-CONTEXT`)، كلها صعبة، كل سؤال فيه فراغان
  يربطهما تركيبٌ منطقي (`لم يكن… بل…`، `كلما… …`، `لا يكفي… بل…`).
- **٢٤ استيعابًا** على **٦ نصوص** جديدة، أربعة أسئلة لكل نص: فكرة رئيسة (صعب)،
  وتفصيل (متوسط)، وغرض الكاتب (متوسط)، ومعنى في السياق (صعب).

موضوعات النصوص: خطأ تقدير الزمن · النسبة بلا أساسها · كلفة التخصّص الضيّق ·
ما يُروى من نصائح الناجحين دون الخاسرين · الاعتراف بالخطأ · قيمة السؤال.

## ٣ — ما طُبّق من دروس المراجعات الأربع

الدفعة كُتبت وهي تمرّ على القواعد السبع التي استخرجتها مراجعات الدفعات ١–٤،
وكلها اشتُقّت من عيب وقعتُ فيه فعلًا:

- **موضع الجواب متوازن**: ٢٥ لكل موضع في هذه الدفعة، و١٢٣ لكل موضع في
  الدفعات الخمس (كا² = ٠٫٠). والمجموعات العددية مرتّبة تصاعديًّا (٢١٢ مجموعة).
- **لا شرح يحيل إلى موضع خيار**، لا بالصيغة المفردة ولا بصيغة الجمع.
- **لا مفتاح متميّز شكلًا**: في كل سؤال، المفتاح والمشتّتات في طول واحد وبنية
  واحدة — وهذا قيّد صياغة بدائل الاستيعاب خاصةً، فجُعلت كلها عبارات متقاربة.
- **لا خيارَين متساويي القيمة** العددية وإن اختلف نصّهما.
- **لا سؤال موسوم «متوسط» وهو خطوة واحدة**: الـ١٢ متوسطًا هنا كلها أسئلة
  تفصيل وغرض في الاستيعاب، وهذه صعوبتها الصحيحة لأن استرجاع جملة صريحة ليس
  «خطوة حسابية».
- **لا تكرار**: الـ١٠٠ استُوردت إلى بنك فيه ١٨٨٩ سؤالًا فقُبلت كلها،
  **صفر مرفوض** — لا تطابق بصمةٍ داخل الدفعة ولا مع المنشور.
- **المشتّتات تناظر أخطاء بعينها** لا أعدادًا عشوائية: متوسط النسبتين مكان
  المرجّح، والأساس الخطأ في نسبة التغير، وعدد الأضلاع مكان عدد الأقطار،
  والمعكوس مكان العدد، والتوقف عند خطوة قبل المطلوبة.

## ٤ — ما لم أفعله

الأسئلة `draft`. الاعتماد قرارك، كما في الدفعات الأربع:

```bash
node server/cli.js import-items  content/batch-005-*.json
node server/cli.js publish-items content/batch-005-*.json \
  --actor hossam198012@gmail.com --note "اعتماد الدفعة الخامسة"
```

ولم أراجعها مراجعةَ ناقدٍ بعد. تأليفُ المئة شيء، وقراءتها سؤالًا سؤالًا بعين
الناقد شيء آخر — وقد أخرجت كل مراجعة من المراجعات الأربع عيوبًا لم يكشفها
مدقّق. فإن أردتَ، أراجعها كما راجعت سابقاتها قبل الاعتماد.
